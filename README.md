# Резюме Юлии Ларюшкиной

Одностраничный сайт-резюме брокера по жилой и коммерческой недвижимости. Реализован на чистых HTML, CSS и JavaScript, не требует сборки и серверной части.

## Локальный запуск

Можно открыть `index.html` напрямую в браузере. Для корректной проверки через локальный HTTP-сервер:

```powershell
python -m http.server 8080
```

После запуска откройте [http://localhost:8080](http://localhost:8080).

## Публикация

Сайт совместим с любым статическим хостингом.

Для публикации через ChatGPT Sites подготовлен каталог `dist` и манифест `.openai/hosting.json`.

### GitHub Pages

1. Загрузите файлы в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main`, каталог `/ (root)` и нажмите **Save**.

### Netlify или Cloudflare Pages

Подключите репозиторий и укажите корень проекта как каталог публикации. Команда сборки не нужна.

## Возможности

- адаптивная верстка для телефона, планшета и компьютера;
- семантическая навигация и видимый клавиатурный фокус;
- прямые ссылки на звонок и письмо;
- копирование текущей ссылки с сообщением о результате;
- печатная версия: при печати раскрывается весь опыт, скрываются навигация и кнопки;
- уважение системной настройки уменьшения анимации.

## Файлы

- `index.html` — структура и содержание;
- `styles.css` — оформление, адаптивная и печатная версии;
- `script.js` — мобильное меню, копирование ссылки и печать.
- `dist/` — готовый статический пакет для хостинга.
