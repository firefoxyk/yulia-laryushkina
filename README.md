# Резюме Юлии Ларюшкиной

Одностраничный сайт-резюме брокера по жилой и коммерческой недвижимости. Сайт реализован на чистых HTML, CSS и JavaScript и публикуется через GitHub Pages.

## Локальный запуск

Сайт можно открыть напрямую через `index.html`. Для проверки по HTTP запустите любой статический сервер из корня репозитория, например:

```powershell
python -m http.server 8080
```

Затем откройте [http://localhost:8080](http://localhost:8080).

## Подготовка `dist`

Исходные файлы находятся в корне репозитория. Перед коммитом обновите готовую к публикации папку:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Скрипт копирует в `dist` только файлы сайта. Относительные пути работают как локально, так и по адресу вида `/yulia-laryushkina/`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` запускается:

- при каждом push в ветку `main`;
- вручную через **Actions → Deploy to GitHub Pages → Run workflow**.

Он собирает `dist`, загружает только эту папку через официальный `actions/upload-pages-artifact` и публикует её с помощью `actions/deploy-pages`.

Для первой публикации в настройках GitHub откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**. После успешного workflow сайт будет доступен по адресу:

```text
https://<имя-пользователя>.github.io/yulia-laryushkina/
```

## Обновление сайта

1. Измените `index.html`, `styles.css` или `script.js` в корне проекта.
2. Запустите `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1`.
3. Проверьте содержимое `dist` и локальную версию.
4. Создайте коммит и отправьте ветку `main` в GitHub. Публикация запустится автоматически.

## Возможности

- адаптивная верстка для телефона, планшета и компьютера;
- семантическая навигация и видимый клавиатурный фокус;
- прямые ссылки на звонок и письмо;
- копирование текущего адреса страницы;
- печатная версия: при печати раскрывается весь опыт, скрываются навигация и кнопки;
- поддержка системной настройки уменьшения анимации.

## Структура

- `index.html` — структура и содержание;
- `styles.css` — оформление, адаптивная и печатная версии;
- `script.js` — мобильное меню, копирование ссылки и печать;
- `scripts/build.ps1` — подготовка статического пакета;
- `dist/` — папка, публикуемая на GitHub Pages;
- `.github/workflows/pages.yml` — автоматическая публикация.
